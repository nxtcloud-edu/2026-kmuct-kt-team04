- 카카오 검색 API 직접 호출로 실제 장소 ID·이름·좌표 반환 확인.

  카카오 장소 ID `7975172`, 위도 `35.1597225815149`, 경도 `129.159908332386`.
- 처음 상호 검색은 결과가 없어 핀을 생성하지 않았으며, 일반 추천 검색어를 지역+업종으로 조정한 뒤 성공.
- 새 브라우저 탭에서도 AI 대화와 핀 1개가 유지됨.

추가적인 타임블록 누락 요청의 브라우저 전송은 자동 승인 검토에서 거절되어 실행하지 않았습니다.
해당 조건의 검증은 위 로컬 자동 테스트 결과입니다.
AI·카카오 호출은 실제 API이며 데이터 저장은 로컬 파일입니다. AWS 배포, 지도 마커 표시,
서로 다른 로그인 사용자 사이의 실시간 동작은 이번 검증에 포함되지 않습니다.

의존성 설치 시 npm audit 경고가 있어 비호환 변경 없는 `npm audit fix`를 실행했습니다.
Amplify 개발/배포 도구의 간접 의존성에 경고가 남아 있습니다. 강제 구버전 전환은 하지 않았습니다.
`npm audit --omit=dev` 기준 런타임 의존성의 알려진 취약점은 0건입니다.
배포 전후 도구 업데이트 가능 여부를 확인하고, 외부에서 받은 임의 스키마/SQL/CSV를 코드 생성 도구에 입력하지 않습니다.
