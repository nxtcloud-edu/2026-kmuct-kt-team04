# 검증 기록

2026-09-20 로컬 검증:

- 서버/구독 권한 테스트 14개 통과 (실제 서비스 로직 + 메모리 저장소, AppSync 유틸리티 대체)
- 백엔드 TypeScript 검사 통과
- 프런트 빌드 및 코드 검사 통과
- Cognito/AppSync/Lambda/DynamoDB 전체 CDK 템플릿 생성과 함수 번들 성공
- 생성된 리소스를 AWS에 배포한 것은 아님

테스트는 외부 DB 통신과 실제 AppSync WebSocket을 대체하므로 실환경 통합 검증을 대신하지 않습니다.
배포 후 점검 항목은 DEPLOYMENT.md를 참고합니다.

의존성 설치 시 npm audit 경고가 있어 비호환 변경 없는 `npm audit fix`를 실행했습니다.
Amplify 개발/배포 도구의 간접 의존성에 경고가 남아 있습니다. 강제 구버전 전환은 하지 않았습니다.
`npm audit --omit=dev` 기준 런타임 의존성의 알려진 취약점은 0건입니다.
배포 전후 도구 업데이트 가능 여부를 확인하고, 외부에서 받은 임의 스키마/SQL/CSV를 코드 생성 도구에 입력하지 않습니다.
